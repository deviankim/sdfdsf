# 라스트 펄롱 (Last Furlong)

브라우저에서 바로 즐기는 짧은 예측형 경마 게임입니다.

## 게임 방식

- 6두의 출전마는 속도, 지구력, 출발, 막판, 안정성, 컨디션 속성을 가집니다.
- 거리와 주로 상태에 따라 각 능력치의 중요도가 달라집니다.
- 현재 조건을 반영한 몬테카를로 시뮬레이션으로 예상 승률과 배당을 보여줍니다.
- 실제 레이스에는 구간별 페이스 변동, 출발 편차, 진로 방해 등의 랜덤 요소가 적용되어 결과를 완벽히 예측할 수 없습니다.
- 실제 화폐가 아닌 게임 내 가상 코인만 사용합니다.

## 실행

별도 빌드 과정이 없는 정적 사이트입니다. `index.html`을 열거나 GitHub Pages에서 바로 실행할 수 있습니다.

## 배포

`main` 브랜치에 push되면 `.github/workflows/pages.yml` 워크플로가 GitHub Pages로 정적 파일을 배포합니다.
